# Fight Ball

A 3v3 cartoon arena game in the browser: Smash-style brawling meets soccer. Built with three.js.

**Play:** open the GitHub Pages site for this repo.

- **Solo / Local:** play right away against bots.
- **Online:** enter a name, click **Create room**, then share the invite link (`?room=CODE`). Friends click it and press **Join room**. Up to 6 players; empty slots are filled with bots. You can also join a match in progress (take over a bot or an open slot) or spectate.

Online play is peer-to-peer (WebRTC via Trystero); the host's browser runs the match. No server is needed.

## Controls
| Action | Keyboard / mouse | Controller |
|---|---|---|
| Move / camera | WASD / mouse | Left stick / right stick |
| Jump (double) | Space | A |
| Punch (hold to charge) | Left click or J | X |
| Kick (hold to charge) | Right click or K | B |
| Skill 1 / 2 | Q / E | LB / RB |
| Shield / parry | F or L | LT |
| Sprint | Shift | RT |
| Ball cam | C | Y |
| Stats (hold) | Tab | View |
| Pause | Esc | Start |

All controls can be rebound from the menu.
